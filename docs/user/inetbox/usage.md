# Inetbox Usage

This page is a placeholder for Inetbox usage documentation.
Once setup has completed, click the Pages button and scroll until you see the Inetbox Overview page.

Please refer to the manufaturers operating instructions for the CP Plus.

Below is a link to all the error codes suppoted by the Inetbox addon.
[Error Codes](truma-error-codes.md)

When an error occures a yellow warning is displayed on the Inetbox overview page.
A notification is also sent to the Venus OS, Notifications page.
